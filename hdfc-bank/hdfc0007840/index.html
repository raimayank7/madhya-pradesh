How the code HDFC0007840 is built

HDFC is the bank part: the letters of HDFC Bank. The fifth character is always the digit 0. 007840 is the part that names this branch.

The MICR code 474240015 is the number printed along the bottom of this branch's cheques. 474 is the city (the same three digits that begin the PIN code 474005), 240 is the bank and 015 is the branch.
